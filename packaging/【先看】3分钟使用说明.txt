莫宁桌宠 0.1.8 - 3 分钟上手
===============================

适用系统：Windows 10 / Windows 11，64 位。
桌宠不需要安装 Node.js；本包不包含 API Key 或第三方弹幕监听器。

第一次使用
----------
1. 把 ZIP 完整解压到一个新的普通文件夹。
   不要在压缩包预览窗口运行，也不要只复制“莫宁桌宠.exe”。

2. 如果需要 AI 弹幕回复，双击“配置OpenCode Go密钥.bat”，输入你自己的 Key。
   Key 不会显示在屏幕上，只写入当前文件夹的 .env。
   不配置也能使用排队、进场欢迎和内置莫宁兜底台词。

3. 双击“下载弹幕监听器.url”，从作者官方 Gitee 发行页下载 Release_V2.8.0.zip。
   不要下载源码包 v2.8.0.zip 或 v2.8.0.tar.gz。

4. 把监听器解压到它自己的文件夹，以管理员身份启动。
   首次运行只有在确认来源可信并理解证书、代理风险后，才允许它安装证书。

5. 打开抖音直播伴侣并开播，再用 Chrome 或 Edge 打开目标直播间。
   监听器窗口出现目标直播间的普通文字弹幕，才表示抓取成功。

6. 双击“莫宁桌宠.exe”。右键莫宁查看菜单。
   “弹幕已连接”只代表桌宠连到了本机 8888 端口。

用两条弹幕测试
--------------
先用另一个抖音账号发送：
  莫宁你好

再发送：
  帮帮 扫码 测试

排队格式：
  单子 扫码 深塔12层
  帮帮 手机号 全息boss
  我几号
  取消排队

“手机号”只代表登录方式，不要发送真实手机号、验证码或密码。
莫宁回复只显示在桌宠气泡内，不会自动发回抖音直播间。

最常用操作
----------
- 右键莫宁：排队、尺寸、进场欢迎、提示音、空闲台词和窗口置顶。
- 进场欢迎不调用 AI；同一观众 10 分钟内不重复，人多时最多每 5 秒显示一次。
- 关闭“窗口置顶”：其他窗口可以盖住莫宁。
- 开启鼠标穿透后点不到：按 Ctrl+Alt+M，或从系统托盘解除。
- 想退出：任务栏右下角托盘 → 右键莫宁 →“退出莫宁桌宠”。

出问题先看这里
--------------
- 监听器有弹幕但莫宁无反应：确认 EXE 是 0.1.8，不是旧版本。
- 没有进场欢迎：确认右键菜单中已开启；高频进场不会每个人都立刻弹出。
- 没连接：确认监听器仍在运行并监听 8888，等待最多 15 秒自动重连。
- AI 显示缺少密钥：重新运行配置脚本；排队与本地兜底不受影响。
- 监听器关闭后无法上网：运行监听器自带的关闭代理脚本，或在 Windows 设置中关闭代理服务器。

本包没有任何人的 API Key。不要把自己生成的 .env 上传、截图或转发给别人。
