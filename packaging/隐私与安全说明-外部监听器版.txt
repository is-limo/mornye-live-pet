莫宁桌宠 0.1.8 - 隐私与安全说明
================================

1. 本分享包不包含 API Key、.env、第三方弹幕监听器、根证书、私钥、直播间号、弹幕记录、排队记录、日志、Cookie、会话或本机路径。
2. .env.example 中的 OPENCODE_GO_API_KEY 为空，仅用于说明配置格式。
3. “配置OpenCode Go密钥.bat”只在使用者自己的电脑上生成 .env；输入内容不会显示。生成后的 .env 不得上传、截图或转发。
4. 桌宠不会自动读取 Hermes 或其他程序目录中的凭据，只读取明确配置给莫宁桌宠的密钥位置。
5. 莫宁人格提示词和本地兜底台词内置在桌宠程序中；EXE 与源码不包含 API Key。
6. 排队指令只在本机处理。启用 AI 时，普通弹幕及最近最多 3 条语境会在遮盖手机号、验证码和过长数字后发送给 OpenCode Go。
7. AI 回复只显示在莫宁气泡中，不会自动发送到抖音。进场欢迎使用本地固定台词，不调用 AI、不进入语境、不写入队列。
8. 队列保存在使用者自己的应用数据目录；不保存监听器提供的原始观众 ID。
9. 日志不记录弹幕正文、AI 请求正文或密钥；配置和队列使用原子写入。
10. 第三方监听器需由使用者自行从官方发行页下载。它可能安装本地根证书、修改系统代理并请求管理员权限；只在理解风险并确认来源时运行。
11. 不要为了运行监听器关闭杀毒软件或 Windows 防火墙。若被拦截，应停止并核对来源。
12. 任何曾被放入旧分享包或发给他人的 Key 都应立即在 OpenCode Go 后台轮换或作废；删除本地文件不能让已发副本失效。
