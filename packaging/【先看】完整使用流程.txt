莫宁桌宠 0.1.8 - 完整使用流程
================================

适用系统：Windows 10 / Windows 11，64 位。
本包只包含莫宁桌宠、空白配置示例和说明，不包含 API Key 或第三方弹幕监听器。

一、替换旧版本
--------------
1. 在任务栏右下角找到莫宁托盘图标，右键选择“退出莫宁桌宠”。
2. 不要覆盖旧文件夹；把本 ZIP 完整解压到一个新的普通文件夹。
3. 删除以前收到的含共享 Key 的旧 ZIP，并在 OpenCode Go 后台作废旧 Key。

二、配置 AI（可选）
------------------
1. 双击“配置OpenCode Go密钥.bat”。
2. 输入你自己的 OPENCODE_GO_API_KEY；输入内容不会显示。
3. 脚本只在当前文件夹生成 .env。不要上传、截图或转发该文件。
4. 不配置 Key 时，排队、欢迎和本地兜底仍然可用。

三、启动弹幕监听器
------------------
1. 从“下载弹幕监听器.url”进入作者官方 Gitee 发行页。
2. 下载 Release_V2.8.0.zip，不要下载源码压缩包。
3. 将监听器完整解压到它自己的文件夹。
4. 先以管理员身份启动监听器；首次运行只在确认来源可信时安装证书。
5. 看到 8888 服务启动后，再用 Chrome 或 Edge 打开目标抖音直播间。
6. 控制台出现普通文字弹幕，才代表目标直播间已经被捕获。

四、启动莫宁
------------
1. 双击“莫宁桌宠.exe”或“仅启动莫宁桌宠.bat”。
2. 右键莫宁查看状态；显示“弹幕已连接”即为端口连接成功。
3. 状态点是偏灰的豆绿色，以菜单文字为准。
4. 桌宠会自动重连 ws://127.0.0.1:8888，启动先后不影响最终连接。
5. “窗口置顶”和“进场欢迎”都可在莫宁右键菜单或托盘中切换并自动保存。

五、测试弹幕和排队
------------------
先用另一个抖音账号发送普通文字：
  莫宁你好

再发送标准排队口令：
  帮帮 扫码 测试
  单子 扫码 深塔12层
  我几号
  取消排队

“单子 / 套餐 / 蛋子”进入优先队列；“帮帮 / 帮打”进入普通队列。
“手机号”只表示登录方式，不要发送真实手机号、验证码或密码。
同名观众通过本地哈希分开排队；原始抖音观众 ID 不会保存或发送给 AI。
主播右键莫宁，可执行“下一号”“完成并下一位”“过号”和“暂停排队”。

六、进场欢迎
------------
观众进入直播间时，莫宁会显示“欢迎 @昵称”的本地气泡。
它不调用 OpenCode Go、不发送回抖音、不进入 AI 语境，也不写入队列。
同一观众 10 分钟内只欢迎一次；人多时全局最多每 5 秒显示一次。

七、常见问题
------------
- 监听器有弹幕、莫宁显示已连接却无反应：确认运行的是 0.1.8。
- 没有进场欢迎：确认设置已开启，并确认监听器能收到“进入直播间”事件。
- 弹幕未连接：确认监听器仍在运行，端口为 8888，并等待自动重连。
- 排队无反应：先发“帮帮 扫码 测试”，并确保它是普通文字弹幕。
- AI 无法联网或缺少 Key：排队仍可工作，普通回复会使用本地兜底短句。
- 点不到莫宁：按 Ctrl+Alt+M，或从托盘解除鼠标穿透。
- 监听器退出后无法上网：运行其关闭代理脚本，或在 Windows 设置中关闭代理服务器。

重要：任何回复都只显示在桌宠气泡内，不会自动发送回抖音直播间。
