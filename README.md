# 莫宁桌宠

Windows 直播场景下的本地透明桌宠：接收 DouyinBarrageGrab 推送的抖音弹幕与进场事件，维护帮打排队，并可通过 OpenCode Go 的 DeepSeek 模型生成莫宁风格短回复。所有内容只显示在桌宠气泡中，不会自动发送回抖音聊天室。

当前版本：`0.1.8`。本项目是个人制作的非官方工具，不代表角色权利人、原作或任何官方账号。

## 功能

- 透明无边框窗口，固定在主屏幕工作区右下角，支持尺寸调整与可选置顶。
- 按 PNG 透明度逐像素命中；模型与菜单外的透明区域不会挡住下层窗口。
- `Ctrl+Alt+M` 切换整窗鼠标穿透，系统托盘可随时解除或退出。
- 连接本机 `ws://127.0.0.1:8888` 的 DouyinBarrageGrab。
- 观众进场本地欢迎：默认开启、可关闭；同一观众 10 分钟内不重复欢迎，全局最多每 5 秒显示一次。
- “单子”优先、“帮帮”普通的双队列，支持叫号、完成、过号、移除、暂停与重启恢复。
- 普通弹幕可调用 OpenCode Go `deepseek-v4-flash`，生成不超过 45 字的角色化回复。
- API 缺失或异常时自动使用本地兜底台词；排队和进场欢迎不依赖 AI。
- 手机号、验证码和过长数字会在进入队列、AI 语境或气泡前被遮盖。

## 数据流

```text
抖音直播伴侣 / 网页直播间
             ↓
DouyinBarrageGrab（本机 ws://127.0.0.1:8888）
             ↓
Electron 主进程
    ├─ 进场事件 → 本地去重与节流 → 欢迎气泡
    ├─ 排队口令 → 本地队列 → 确认与叫号气泡
    └─ 普通弹幕 → OpenCode Go（可选）→ 最终短句
                                          ↓
                              受限 IPC → 桌宠气泡
```

桌宠不会向 DouyinBarrageGrab 回写消息，也不会自动操作抖音直播伴侣。

## 零基础使用

1. 从 GitHub Releases 下载最新的“安全分享版”ZIP，并完整解压。
2. 本包不含 API Key。需要 AI 回复时，双击“配置OpenCode Go密钥.bat”，输入自己的 Key；不配置也能使用排队、进场欢迎和本地兜底。
3. 通过包内链接前往 DouyinBarrageGrab 官方发行页，自行下载并解压 `Release_V2.8.0.zip`。
4. 启动监听器后，再打开抖音直播伴侣及目标直播间。
5. 双击“莫宁桌宠.exe”，右键莫宁查看连接状态与队列。

DouyinBarrageGrab 是独立第三方程序，可能修改系统代理、安装本地根证书并请求管理员权限。请只从其官方发行页下载，在理解风险后运行；本仓库和发布包均不复制该程序或其证书。

## 配置 OpenCode Go

复制 `.env.example` 为 `.env`，只在自己的电脑上填写：

```dotenv
OPENCODE_GO_API_KEY=
```

密钥读取顺序：

1. 当前进程环境变量 `OPENCODE_GO_API_KEY`；
2. 桌宠应用数据目录中的 `.env`；
3. 便携版 EXE 同目录的 `.env`；
4. 环境变量 `MORNYE_CREDENTIALS_FILE` 明确指定的文件。

项目不会自动读取其他程序的凭据。源码仓库、CI 与发布包都不得包含真实 Key。`npm run probe:ai` 可进行一次最小接口探测；它不会打印 Key。

## 排队口令

```text
单子 扫码 深塔12层
帮帮 手机号 全息boss
排队 单子 扫码 周本
我几号
取消排队
```

- `单子 / 套餐 / 蛋子`进入优先队列，`帮帮 / 帮打`进入普通队列。
- 每位观众同时只能有一个等待或进行中的记录。
- 主播通过桌宠右键菜单或托盘执行“下一号 / 完成并下一位 / 过号 / 暂停”。
- “手机号”只代表登录方式；不要在弹幕中发送真实手机号、验证码或密码。

## 隐私与安全

- 普通弹幕只短暂保留在内存中；启用 AI 时，当前弹幕与最近最多 3 条语境会在脱敏后发送给 OpenCode Go。
- 进场欢迎完全在本机生成，不调用 AI、不进入语境、不写入队列。
- `queue.json` 只保存昵称、登录方式类别、脱敏后的帮打内容和用于区分同名观众的截断哈希；不保存监听器提供的原始观众 ID。
- 日志不记录弹幕正文、AI 请求正文或密钥。
- 渲染层启用严格 CSP、沙箱和上下文隔离，不拥有 Node.js 或网络访问能力。
- 发布脚本会拒绝 `.env`、证书、私钥、日志、会话、本机路径和疑似凭据。

安全问题请参阅 [SECURITY.md](SECURITY.md)。素材与再分发边界见 [ASSET-NOTICE.md](ASSET-NOTICE.md)。

## 故障排查

- 状态点红色：监听器未启动，或没有监听本机 8888 端口。
- 显示“弹幕已连接”只代表端口连通；监听器还必须捕获到目标直播间的普通文字弹幕。
- 没有进场欢迎：确认设置已开启且监听器能收到类型 3 事件；高频进场会主动节流。
- AI 显示“缺少密钥”：配置自己的 Key；排队、欢迎和本地兜底仍可工作。
- 点不到莫宁：按 `Ctrl+Alt+M`，或从系统托盘解除鼠标穿透。
- 队列显示“存档异常”：当前内存队列仍可用，但重启可能丢失；直播后检查应用数据目录权限。
